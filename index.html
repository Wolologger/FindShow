Escribe un artista, una ciudad, o ambos. Sin ciudad, se filtra por el radio de arriba; con ciudad, se busca ahí directamente sin límite de distancia.

Opcional — añade tus artistas seguidos como accesos rápidos de búsqueda.

setlist.fm no permite peticiones directas desde el navegador (CORS). Necesitas un proxy propio (mira "Conciertos pasados" en el README para un ejemplo con Azure Functions) o configurar la constante CORS_PROXY_URL en js/app.js.

Datos de conciertos proporcionados por la Ticketmaster Discovery API. Datos de artistas seguidos obtenidos vía la Spotify Web API. Esta aplicación es un proyecto personal, no comercial, y no está afiliada, patrocinada ni respaldada por Ticketmaster/Live Nation ni por Spotify.

Privacidad: esta app no tiene servidor. Todo el procesamiento ocurre en tu navegador. El token de Spotify vive solo en tu sesión y no se envía a terceros salvo a Spotify/Ticketmaster/setlist.fm para hacer las consultas correspondientes. No se usan cookies de seguimiento ni analítica.
