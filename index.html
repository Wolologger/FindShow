> configuración (client id, redirect uri, api key)
Nada de esto se guarda en ningún servidor: vive solo en esta sesión del navegador. Necesitas: 1) crear una app en developer.spotify.com/dashboard con esta misma URL exacta como Redirect URI y el scope user-follow-read activado, y 2) una key gratuita en developer.ticketmaster.com. Para conciertos pasados hace falta además una key gratuita de api.setlist.fm — ojo, esta API no admite peticiones directas desde el navegador (CORS), mira la sección correspondiente del README para las opciones.

Escribe un artista, una ciudad, o ambos. Si dejas la ciudad vacía, se filtra por el radio desde Cantabria del panel de configuración de arriba; si pones una ciudad, se busca ahí directamente sin límite de distancia.

> Conectar con Spotify (opcional) — accesos rápidos a tus artistas seguidos

No hace falta para buscar — la búsqueda de arriba funciona sola con la key de Ticketmaster. Conectar Spotify solo añade tus artistas seguidos como chips de acceso rápido, y una opción para buscarlos todos de golpe.

setlist.fm no permite peticiones directas desde el navegador (CORS). Necesitas un proxy propio (mira "Conciertos pasados" en el README para un ejemplo con Azure Functions) o pegar la URL de uno en el panel de configuración de arriba.
Por qué esto es un archivo y no una llamada a la API: Spotify no expone tus minutos escuchados por ningún endpoint público. La única vía real es pedir tu Historial de streaming extendido desde spotify.com/account/privacy (tarda hasta 30 días). Te llega un .zip con varios .json — súbelos aquí abajo y se calcula todo en tu navegador, sin subir nada a ningún sitio.

Datos de conciertos proporcionados por la Ticketmaster Discovery API. Datos de artistas seguidos obtenidos vía la Spotify Web API. Esta aplicación es un proyecto personal, no comercial, y no está afiliada, patrocinada ni respaldada por Ticketmaster/Live Nation ni por Spotify.

Privacidad: esta app no tiene servidor. Todo el procesamiento ocurre en tu navegador. Las claves de API y el token de acceso viven solo en tu sesión (no se envían a terceros salvo a Spotify/Ticketmaster para hacer las consultas correspondientes) y no se almacenan ni transmiten a ningún servidor propio. No se usan cookies de seguimiento ni analítica.
